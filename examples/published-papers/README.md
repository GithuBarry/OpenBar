# Published paper fixtures

The OpenBar demo image includes two example projects:

- `command-v` — Command-V, ICLR 2026
- `noveltybench` — NoveltyBench, COLM 2025

Each example includes TeX source, figures, maps, paper annotations, and project
instructions. Some examples also include wiki pages and skills. The demo copies
the examples into its writable content directory at startup.
